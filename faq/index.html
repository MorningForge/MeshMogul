FAQ

The details worth asking.

Clear answers before you plan your asset workflow.

What changed in MeshMogul Founding 1.2.1?

Founding 1.2.1 improves local asset saving, publication confirmations, and navigation within nested Models. Messages for unsupported inputs, including child Textures and Decals, are clearer. Read the release notes or get MeshMogul on Creator Store.

Does MeshMogul replace Blender?

No. Use Blender or another dedicated editor for custom topology, sculpting, UV authoring, rigging, or a broader mesh-authoring pipeline. MeshMogul fits supported builds already made in Studio.

Does it support Unions?

Direct Union/CSG conversion is excluded from the current customer workflow. A Union inside a selected container blocks that root; MeshMogul does not silently omit it.

Does it preserve materials and colors?

Supported source colors can be carried in mesh data. Compatible materials, transparency, and appearance states can form separate outputs. Copied properties are not universal visual fidelity. Glass and child Decal/Texture overlays are refused; texture/PBR and MaterialVariant support have explicit boundaries.

How does MeshMogul handle two-sided meshes?

Supported DoubleSided appearance is retained through Preview and reuse. Geometry must be readable and appearance must be supported. Inspect both sides of the Preview and inserted result in your own scene.

Is the original source changed?

The source is retained rather than permanently converted. Preview uses a temporary visual derivative; the workflow manages and restores source visibility during inspection. The derivative does not inherit scripts, constraints, animation, or physics behavior.

Why can one logical asset have multiple MeshIds?

Some supported appearance states require separate physical mesh outputs. MeshMogul keeps their ordered IDs together as one logical asset. A complete grouped result inserts as one Model; a single output inserts as a MeshPart.

Why does publishing use the Command Bar?

The current publication workflow uses an explicit manual Studio handoff. Publish Mesh prepares inspectable text for the current Preview; you run it in the Command Bar. Creating a Preview or preparing a command does not upload anything. Wait for publication confirmation before relying on the asset.

Can I update an existing Mesh AssetId?

No. MeshMogul does not update an existing Mesh AssetId. Current publication creates new mesh assets. There is no automatic update, version rollback, or propagation to placed copies.

Where are remembered assets stored?

In local Studio plugin settings, including ordered confirmed mesh IDs, supported appearance information, source/creator metadata, and publication progress. The library holds 25 recent complete records and up to 100 pinned records. It is not team or cloud sync. Removing a record does not delete its Roblox assets.

What happens if grouped publication only partly completes?

Confirmed IDs are retained. The logical record remains incomplete under Needs attention and cannot Insert. Read the current guidance rather than blindly replaying an uncertain or expired command.

Can I use Roblox Texture Generator on the result?

Texture Generator is a separate Roblox Studio tool for MeshParts. Inspect and save the textured result with its image references; reinserting the original geometry alone is not a backup of later texturing. MeshMogul does not automatically run native AI texturing or track every downstream edit. See the Texture Generator guide.

Will this make my experience faster?

No performance result is guaranteed. Mesh output, triangle count, appearance groups, collision choices, and scene usage all matter. Measure the result in your own experience. The before-and-after comparison guide walks through a fair test.

Where can I install MeshMogul?

Get MeshMogul on Creator Store. Check the supported inputs and current limits before planning a conversion.

What changed in 1.1.1?

Grouped Preview and Assets, multiple supported appearance outputs, improved supported appearance preservation, stale-source and partial-result protection, ordered source MeshId copy, improved inspection and navigation, exact-instance Find, Reset Position, and an in-plugin What’s New panel. Read the release notes.

Does copying a source MeshId publish a new mesh?

No. Source MeshId references identify source geometry and are separate from confirmed output IDs. Copy support does not upload or grant rights to an asset. Publication still requires the explicit guided Studio Command Bar handoff.

What does exact-instance Find locate?

The tracked inserted logical root in the current place. It does not search every place, every matching mesh or your account’s full asset inventory.
