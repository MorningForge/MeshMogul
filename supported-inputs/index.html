Compatibility

Check the build before the bake.

MeshMogul works with supported source and readable content. An unsupported piece blocks the selected root; it is not quietly omitted.

Start here: Direct Unions/CSG, child Decal/Texture overlays, Glass, and unreadable mesh content are outside the current customer workflow. No universal model conversion or performance improvement is promised.

Inspect before Preview.

The upcoming 1.1.1 update adds Mogul Insights for the selected build, Technical Details for supporting evidence, and deeper Model Info for composition, appearance, and source understanding. These tools describe available information within the supported boundary; they do not exhaustively understand every Roblox object or asset.

References shows known source Mesh IDs when available, in the same order as source details. Select the IDs in References and press Ctrl+C to copy. A source ID does not grant access to its geometry.

Appearance: transfer has boundaries.

Supported source colors are carried in mesh data. The upcoming 1.1.1 update improves embedded-color preservation in supported round-trip cases; it does not broaden texture or PBR support. Compatible material, transparency, and reflectance states can be partitioned into separate outputs. Readable UV and image channels are required for supported textured cases.

  • Glass is refused in the current workflow because of appearance fidelity limits.
  • Child Decal and Texture overlays are refused. They are not flattened into a baked image.
  • Texture and SurfaceAppearance support is bounded. Readable, durable image resources and supported channel combinations are required. Arbitrary PBR fidelity is not guaranteed.
  • MaterialVariant is conditional. Supported mapless definitions require compatible definitions at the destination; arbitrary mapped variants are not supported.
  • Copied properties do not prove identical pixels. Inspect Preview and inserted results in your lighting and destination place.

Size, selection, and source.

The source baker checks a limit of 60,000 vertices and 20,000 triangles. There is no general automatic simplification or chunking promise. Multiple independently selected roots refuse; put supported geometry under one root when appropriate.

A deliberate option can exclude fully invisible supported parts. This does not allow unsupported descendants to bypass preflight. Original source is retained; scripts, constraints, source physics, and animation are not copied into the visual derivative.

Publication and reuse.

  • Publishing currently requires a manual Studio Command Bar handoff and Roblox permission to create the requested assets.
  • A grouped logical asset can require several physical mesh uploads. An incomplete result cannot Insert.
  • No automatic same-AssetId updates, rollback, placed-copy propagation, or one-click Creator Store publishing.
  • Assets records are local plugin settings: 25 recent complete records and up to 100 pinned records. Unresolved incomplete records are protected from normal complete-record eviction.
  • No team/cloud sync or guaranteed triangle-count, draw-call, or FPS improvement.
