Upcoming update

Founding · 1.1.1

Understand the selected build before committing to Preview or publication. These highlights describe the update being prepared; no public release date or 1.1.1 distribution availability is asserted here.

  • Mogul Insights. See what matters about the selected build before Preview.
  • Technical Details. Inspect the evidence behind the summary so you can make an informed next step.
  • References. Find known source Mesh IDs when available, ordered consistently with source details. Select the IDs in References, then press Ctrl+C to copy.
  • Model Info. Explore deeper composition, appearance, and source information inside MeshMogul.
  • Clearer MeshPart access diagnostics. Distinguish readable meshes from content Roblox does not expose as editable geometry. Unavailable geometry is reported rather than silently discarded; permissions, ownership, or sharing may be possible causes, not a confirmed diagnosis.
  • Better supported color round trips. Improved preservation of embedded colors in supported round-trip cases, within the existing appearance limits.
  • Clearer publication progress and results. Follow progress and distinguish confirmed results from incomplete publication. Uploads still require the manual Studio Command Bar handoff.

The multi-output, grouped Preview, and grouped Assets workflow introduced in 1.1.0 continues in 1.1.1.

Previous version

Founding · 1.1.0

Retained highlights from the 1.1.0 release panel; no public distribution date is asserted here.

  • Multi-output meshes. Supported appearance groups can produce ordered physical outputs within one logical result.
  • Grouped Preview. Multi-output results remain one logical Preview for inspection.
  • Appearance separation. Compatible material and transparency states can remain separate instead of being forced into an invalid single output.
  • Grouped Assets lifecycle. One record remembers and reinserts its ordered mesh IDs.
  • Primitive surface shading. Explicit normals preserve hard and smooth shading on supported converted primitives; this is not a universal appearance guarantee.
  • Preview inspection. Select Preview, inspect with Studio Move/Rotate, and use Reset Position to restore the approved position and angle.
  • Partial-publication state. Confirmed partial results are kept; an incomplete grouped publication is not presented as complete or blindly retried.

The Founding workflow

Build → Preview → Publish → Remember → Reuse. Original source is retained, publication uses an explicit manual Studio Command Bar handoff, and remembered Assets are local plugin settings.

Direct Unions, arbitrary PBR fidelity, automatic same-ID updates, and team/cloud sync are not part of the current promise. Read current compatibility and limits.
