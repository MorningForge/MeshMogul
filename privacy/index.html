Privacy & data

Know where the data goes.

The marketing website, local plugin records, and Roblox asset publication are separate parts of the workflow.

This website

This site serves static HTML, CSS, and images. It has no analytics scripts, tracking pixels, cookies set by site code, forms, accounts, or browser storage. It does not collect a mailing list or send visitor input to a MeshMogul backend.

GitHub Pages hosts this static website. The host processes requests under its own policies, including technical request information. See GitHub’s privacy statement. Following a Roblox or GitHub link takes you to a separate service.

Local plugin settings

MeshMogul uses Studio plugin settings for remembered asset records and preferences. Asset records include mesh IDs, supported appearance descriptors, creator/source metadata (which can include source names and paths), placement information, and publication progress. Local AI Brief history can retain saved instructions and context.

These local records are not a MeshMogul team/cloud sync service or a backup of source geometry. Removing an Assets record does not delete the corresponding Roblox mesh assets. Treat saved context and any text you choose to share according to its content.

Publication and reuse use Roblox

The explicit Command Bar handoff submits mesh content to Roblox under the selected creator destination. Reuse loads published mesh content; asset thumbnails also come from Roblox. Those service interactions are separate from local record storage and subject to Roblox permissions and policies.

Generating a command is distinct from executing it. Do not run it unless you intend to create assets. This page makes no blanket “offline-only” or “no data ever leaves Studio” claim.

AI context is a handoff

Preparing context is not autonomous provider integration. If you copy instructions or source context into another tool, that sharing is your explicit action and the destination’s policies apply. Review the text before sharing.

Ownership and notices

Scope of this statement

These statements describe the static site code and the current plugin’s local-record and publication mechanisms. They do not assert the absence of all platform logging or establish a Roblox-wide privacy policy. See Roblox’s privacy policy.
