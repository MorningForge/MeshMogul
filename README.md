## What MeshMogul Does

MeshMogul lets creators turn supported Studio builds into inspectable, publishable, and reusable mesh assets directly inside Roblox Studio without switching back and forth to an external 3D modeling app.

The five-step workflow stays completely within Studio:
1. **Build**: Create or select supported Parts, MeshParts, Models, or solid Unions.
2. **Preview**: Inspect the grouped result and appearance before committing.
3. **Publish**: Review and manually run the generated publication command in Studio’s Command Bar.
4. **Remember**: Confirmed mesh IDs are kept together in your local Studio plugin settings.
5. **Reuse**: Insert fresh copies into any place whenever you need them again.

MeshMogul preserves your original build intact.

## Compatibility & Explicit Boundaries

- **Supported Inputs**: Works with supported Parts, solid Union/CSG assemblies, and transparent Glass Unions.
- **Explicit Limits**: Child Decal/Texture overlays and unreadable mesh geometry remain unsupported.
- **Deliberate Publication**: Publishing requires reviewing and manually running the generated command in Studio's Command Bar; there is no automatic background publishing or cloud sync.
- **Local Library**: Your assets library stays local to your Studio installation; it does not replace backups of your source build.
- Review full details on [Supported Inputs & Limits](https://morningforge.github.io/MeshMogul/supported-inputs/).
