Studio field guide · 1.2.0 · Draft

ProceduralModel / Roblox Assistant Output to Reusable Mesh Asset

Inspect generated Studio output, let generation settle, and use only supported geometry for a reusable visual mesh derivative.

Keep in mind. Editorial draft. Check the current Studio interface and your asset permissions. MeshMogul steps apply only to supported inputs.

Generated output still needs inspection.

Roblox Assistant output can take different forms. A script, a regular Model, and a ProceduralModel are not the same input. Judge the actual instances and geometry in Studio rather than assuming all generated content is convertible.

When the source is a ProceduralModel.

MeshMogul’s supported path waits for current generated BaseParts to stabilize, then creates a frozen visual derivative. It retains the original source and Generator. Failed, empty, nested, detached, or stale generation is refused.

  1. Let generation finish and inspect the generated result.
  2. Select the single supported root. Check geometry and appearance in preflight.
  3. Create the retained Preview and compare it with the generated build.
  4. If generation or source changes, refresh the Preview before preparing publication.
  5. Review and manually run the current Command Bar handoff only when ready to upload.
  6. Reuse the complete Assets record after all mesh outputs confirm.

When the output is a regular Model.

The normal container rules apply. Supported nested Parts can fit the workflow; unsupported geometry anywhere in the collected root blocks it. Scripts and constraints are not copied into the visual mesh result. Review scripts independently before running generated code.

Separate geometry from behavior.

A reusable visual derivative does not preserve the Generator’s live behavior, animation, hierarchy, or source physics. Keep the original if you want to regenerate or edit it later.

MeshMogul is not an autonomous Assistant integration. Its generated-source workflow does not imply AI execution, automatic editing, or publishing authority. Supported input and explicit creator actions remain the boundary, whether a human or an assistant helped create the source.
